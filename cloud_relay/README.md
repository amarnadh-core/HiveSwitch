# HiveSwitch Cloud Relay Server

HTTP intermediary that replaces the shared `.local-cloud` folder. Helpers on
different networks can upload/download world snapshots, heartbeat session state,
and participate in leader elections through this server.

## Quick Start

```powershell
# 1. Create a config file with a fresh API key
python -m cloud_relay.server init

# 2. Start the relay
python -m cloud_relay.server
```

The server will print the API key on first init. Share it with your helpers.

## Config

`cloud_relay.json`:

```json
{
  "host": "0.0.0.0",
  "port": 9000,
  "data_dir": "relay_data",
  "api_key": "<auto-generated>",
  "max_upload_bytes": 52428800,
  "max_snapshots_per_world": 20
}
```

## Authentication

All requests must include the API key as a Bearer token:

```
Authorization: Bearer <api_key>
```

If `api_key` is empty in the config, authentication is disabled (open access).

## API Endpoints

### Health
| Method | Path      | Description          |
|--------|-----------|----------------------|
| GET    | `/health` | Server health check  |

### Session
| Method | Path                          | Description                  |
|--------|-------------------------------|------------------------------|
| GET    | `/worlds/{id}/session`        | Read session metadata        |
| PUT    | `/worlds/{id}/session`        | Write session (heartbeat)    |

### Snapshots
| Method | Path                                              | Description                |
|--------|---------------------------------------------------|----------------------------|
| GET    | `/worlds/{id}/latest`                             | Latest snapshot pointer    |
| PUT    | `/worlds/{id}/latest`                             | Update latest pointer      |
| GET    | `/worlds/{id}/snapshots`                          | List snapshot IDs          |
| GET    | `/worlds/{id}/snapshots/{sid}/meta`               | Snapshot metadata          |
| PUT    | `/worlds/{id}/snapshots/{sid}/meta`               | Upload snapshot metadata   |
| GET    | `/worlds/{id}/snapshots/{sid}/manifest`           | Snapshot file manifest     |
| PUT    | `/worlds/{id}/snapshots/{sid}/manifest`           | Upload manifest            |
| GET    | `/worlds/{id}/snapshots/{sid}/files/{path}`       | Download a world file      |
| PUT    | `/worlds/{id}/snapshots/{sid}/files/{path}`       | Upload a world file        |
| POST   | `/worlds/{id}/snapshots/{sid}/complete`           | Mark snapshot complete     |

### Election
| Method | Path                          | Description                  |
|--------|-------------------------------|------------------------------|
| POST   | `/worlds/{id}/election`       | Attempt election lock        |
| GET    | `/worlds/{id}/election`       | Check lock status            |
| DELETE | `/worlds/{id}/election`       | Release lock                 |

## Storage Layout

The relay stores data in the same layout as `.local-cloud`:

```
relay_data/
  worlds/
    prototype-world/
      latest.json
      session.json
      election.lock
      snapshots/
        20260508T135538Z/
          meta.json
          manifest.json
          .complete
          world/
            level.dat
            region/r.0.0.mca
```
